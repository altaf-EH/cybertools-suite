Thank you for installing CyberTools Suite!

FEATURES:
- CDR Analyzer: Telecom Call Detail Record Investigation
- Log Analyzer: Security Log Investigation
- FinTrack: Financial Fraud & Mule Account Analysis
- AI Insights: Local AI-powered analysis (via Ollama)
- Case Management: Organize investigations
- Report Generation: PDF, TXT, XLSX reports

REQUIREMENTS:
- Windows 10 or 11 (64-bit)
- Minimum 8GB RAM (16GB recommended for AI Insights)
- Disk space: 500MB (without AI models)

GETTING STARTED:
1. Launch CyberTools Suite from Start Menu or Desktop
2. Create a new case in "Case Management"
3. Select an engine (CDR Analyzer, Log Analyzer, or FinTrack)
4. Add your evidence file
5. Run the analysis
6. Review the generated reports

AI INSIGHTS (OPTIONAL):
1. Install Ollama from https://ollama.com
2. In Settings > AI Insights, click "Recheck Status"
3. Click "Download Model" to get the local AI model
4. Enable AI Insights
